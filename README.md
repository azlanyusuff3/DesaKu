# DesaKu 🛖

Cozy kampung builder (PWA). Bina jalan, rumah, warung, surau, sekolah… penduduk datang, kampung jadi Pekan → Bandar → Bandaraya.

## Jimat bateri
- Skrin dilukis **hanya bila ada perubahan** (takde gelung 60fps)
- Animasi penduduk 12fps, boleh dimatikan (☰ → Animasi = Mod Jimat)
- Ekonomi dikira ikut cap masa; semua berhenti bila app ditutup
- Duit idle bila app ditutup (50%, max 8 jam)

## Art (pilihan)
Game guna bangunan yang dilukis dengan code. Untuk tukar ke art ChatGPT, letak `.webp` dalam `sprites/` dan tambah nama dalam `sprites/list.json`
(contoh `rumah_0`, `rumah_1`, `rumah_2`, `warung`, `surau`…). Lihat `sprites/PROMPTS.md`.
